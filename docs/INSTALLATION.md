# 🐧 Installation Guide: Linux & macOS

This guide provides instructions for deploying **Prompt-Router** on **Linux** (Ubuntu, Debian, Fedora, Arch, CentOS) and **macOS** (Apple Silicon M-series and Intel), including background daemonization via **PM2** or **systemd**.

---

## 1. System Requirements

* **Node.js**: **v24.0.0 or higher** (Prompt-Router uses Node 24's native `node:sqlite` / `DatabaseSync` for ACID-compliant transaction auditing with zero native C++ compilation).
* **Git**: To clone the repository.
* **Memory**: Minimum 256 MB RAM (typical memory footprint is ~65 MB).
* **Port**: Default `4000` (configurable via `PORT` environment variable).

---

## 2. Installing Node.js 24+

### macOS (via Homebrew)
```bash
# Install Homebrew if not already installed
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install Node 24
brew install node@24
brew link node@24 --force --overwrite

# Verify installation
node -v # Should output v24.x.x
```

### Linux & macOS (via NVM - Node Version Manager)
```bash
# Install NVM
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# Reload shell configuration
source ~/.bashrc  # On Ubuntu/Debian/Fedora
source ~/.zshrc   # On macOS or Zsh shells

# Install and activate Node 24
nvm install 24
nvm use 24
nvm alias default 24

# Verify installation
node -v # Should output v24.x.x
```

## 3. Clone and Build

```bash
# Clone the repository
git clone https://github.com/robinwintertaylor/Prompt-Router.git
cd Prompt-Router

# Install project dependencies
npm install

# Compile TypeScript into native ES Modules in dist/
npm run build
```

## 4. Environment Configuration

Copy the example environment template and configure your API credentials:

```bash
cp .env.example .env
nano .env # Or use vim, micro, or code
```

Configure your environment settings:
```env
PORT=4000
HOST=0.0.0.0

# Upstream Provider Keys
TYPESAFE_API_KEY=ts_live_...       # https://typesafe.ai (120ms Jev System One)
MAMMOUTH_API_KEY=sk-mammouth-...   # https://mammouth.ai (Primary Provider)
OPENROUTER_API_KEY=sk-or-v1-...    # https://openrouter.ai (Fallback Aggregator)

# Default Strategy
ROUTING_STRATEGY=cost_optimized    # cost_optimized, performance_optimized, balanced
DEFAULT_PROVIDER=mammouth
```

## 5. Background Process Management (PM2)

To run Prompt-Router continuously in the background and ensure automatic restart on system reboots:

### 1. Install PM2 Globally
```bash
npm install -g pm2
```

### 2. Start Prompt-Router
From the root of the `Prompt-Router` project:
```bash
pm2 start dist/index.js --name prompt-router
```

### 3. Configure Boot Startup
```bash
pm2 startup
```
*Copy and execute the `sudo env PATH=...` command generated by PM2.*

Then save the active process list:
```bash
pm2 save
```

### 4. Process Monitoring Commands
```bash
pm2 status          # Check gateway status
pm2 logs            # View live proxy & streaming logs
pm2 restart prompt-router
pm2 stop prompt-router
```

## 6. Alternative: Linux systemd Service

If you prefer running as a standard Linux systemd daemon without PM2:

Create `/etc/systemd/system/prompt-router.service`:
```ini
[Unit]
Description=Prompt-Router LLM Gateway
After=network.target

[Service]
Type=simple
User=your_username
WorkingDirectory=/home/your_username/Prompt-Router
ExecStart=/usr/bin/node dist/index.js
Restart=always
RestartSec=5
Environment=NODE_ENV=production
EnvironmentFile=/home/your_username/Prompt-Router/.env

[Install]
WantedBy=multi-user.target
```

Enable and start the service:
```bash
sudo systemctl daemon-reload
sudo systemctl enable prompt-router
sudo systemctl start prompt-router
sudo systemctl status prompt-router
```

## 7. Connecting Client Applications on Linux/macOS

### Goose AI Agent
1. Create the `custom_providers` directory:
   ```bash
   mkdir -p ~/.config/goose/custom_providers
   ```
2. Create `~/.config/goose/custom_providers/custom_prompt_router.json`:
   ```json
   {
     "name": "custom_prompt_router",
     "engine": "openai",
     "display_name": "Prompt-Router (Jev)",
     "description": "Schema-constrained Jev System One smart router gateway",
     "api_key_env": "PROMPT_ROUTER_API_KEY",
     "base_url": "http://localhost:4000/v1",
     "models": [
       {
         "name": "auto",
         "context_limit": 200000,
         "reasoning": true
       },
       {
         "name": "jev-smart-router",
         "context_limit": 200000,
         "reasoning": true
       }
     ]
   }
   ```
3. Set your environment variable in `~/.bashrc` or `~/.zshrc`:
   ```bash
   export PROMPT_ROUTER_API_KEY="prompt-router"
   ```
4. Run Goose:
   ```bash
   goose session --provider custom_prompt_router --model auto
   ```

### Claude Code CLI
```bash
export OPENAI_BASE_URL="http://localhost:4000/v1"
export OPENAI_API_KEY="prompt-router"
claude --model auto
```

### Cursor IDE & VS Code (Cline / Continue)
* **Base URL**: `http://localhost:4000/v1`
* **API Key**: `prompt-router`
* **Model**: `auto` (or `jev-smart-router`)
